# Reference Sheet for Thesis Report Writing
**Unsupervised Epileptic Seizure Temporal Localization in Scalp EEG using Graph Autoencoder and Change Point Detection**

**Purpose.** This file consolidates verification notes for all 86 references gathered for this thesis (78 PDFs read directly + WHO fact sheet + 3 DOI-only references supplied by the author + 4 corpus/dataset citations). Each entry was checked against the actual paper text (abstract, and where relevant, tables/figures/body) before being logged here — not assumed from memory. Use this file when writing citations: look up the code (e.g. `E4`, `H10`) to get the full citation, the exact number/quote to use, which report section it supports, and any caveat that must travel with it.

**Codes.** Groups follow the order papers were verified: A1–A12, B1–B11, C1–C9, D1–D5, E1–E14, F1–F7, G1–G9, H1–H11 (= 78 PDFs), plus I1–I4 (WHO + 3 DOI-only refs), plus J1–J4 (the corpus's own citation page + the montage standard) = **86 references total**.

**Verification-method key** (stated per entry where relevant):
- *VERIFIED FROM SOURCE* — number/quote independently confirmed by reading the actual PDF text (abstract, table, or body).
- *VERIFIED FROM PROVIDED TEXT* — confirmed from abstract/intro/section-snippets text supplied directly (no full PDF access, e.g. paywalled papers).
- No explicit tag — bibliographic/architectural description read directly from the PDF; no specific number required independent verification.

## ⚠️ Critical flags — read before writing Ch.1 / Ch.4 / §VII literature-comparison tables

Five issues were discovered during verification that affect numbers or metadata already used elsewhere in the project's own documents. Resolve or account for these before quoting the affected figures in the report.

**1. SzCORE paper (D4) does not contain the "RF/Transformer/XGBoost CHB-MIT" benchmark table.** `RESULTS_OF_RECORD.md` §5 and `Proposed_solution_updated_v5.md` §VII cite "SzCORE paper's own supervised CHB-MIT baselines (Table 2): RF sens 0.37/FP-day 1.66; Transformer sens 0.765/FP-day 40.6; XGBoost sens 0.671/FP-day 2.09" as coming from the SzCORE *Epilepsia* paper (D4, DOI 10.1111/epi.18113). Full-text search of D4 for "CHB-MIT" returns **zero hits** — D4 is a framework/protocol paper and contains no CHB-MIT benchmark table at all. The numbers also do not match D5's (SzCORE Challenge report) actual leaderboard, which scores a *different, private* EMU dataset. `PROVENANCE_MAP.md` had already partially caught this (flagging the Transformer row as TUH, not CHB-MIT), but the RF/XGBoost rows have **no traceable source** in either SzCORE paper received. **Action: do not cite D4 for these numbers; either locate the actual source paper before using them, or drop the row.**

**2. Three different "LaBraM/CBraMod CHB-MIT AUROC" numbers exist across three different papers/protocols — do not conflate them:**
- **0.868 / 0.8679** — CBraMod's/LaBraM's own **in-domain, standard-split** numbers, independently confirmed at the source in **H11** (CBraMod's own paper, Table 8: CBraMod AUROC 0.8892) and cross-confirmed in **F3** (CSBrain's comparison table: CBraMod 0.8892, LaBraM 0.8679). Cite **H11 or F3** for this number, never H6.
- **0.792 (LaBraM) / 0.777 (CBraMod)** — the same models' **strict out-of-domain, LOSO** numbers, verified word-for-word at the source in **H10** ("What EEG Foundation Models Encode," Zare 2026): "BIOT 0.862 (in-domain)... REVE 0.793, LaBraM 0.792, CBraMod 0.777... classical baseline 0.700." Cite **H10** for any out-of-domain/LOSO framing.
- **H6 (LaBraM's own original paper) contains NO CHB-MIT evaluation at all** (0 mentions found) — its own downstream tasks are TUAB and TUEV only. Cite H6 only for LaBraM's architecture/pretraining-corpus claims, never for a CHB-MIT number.
- **Always state which protocol (standard split vs. strict LOSO) a LaBraM/CBraMod number came from.**

**3. PII cross-reference between two similarly-labeled BSPC papers is now resolved.** `Spatial_Localization_...md` previously risked conflating two *Biomedical Signal Processing and Control* articles under a shared "explainable/channel-annotated" label. Confirmed distinct:
- **I2** (PII `S174680942400380X`, DOI 10.1016/j.bspc.2024.106322) = Amrani, Adadi & Berrada — lobe/hemisphere **localization/lateralization** paper (85.43%/86%/79.4% on CHB-MIT/Siena/Helsinki).
- **E13** (PII `S1746809424015428`, DOI 10.1016/j.bspc.2024.107484) = Wong et al. — **DeepSHAP channel-sensitivity** paper (0.59 overall sensitivity).
- These are two different articles in the same journal with visually similar PII strings — do not merge their numbers.

**4. I3's publication year needs a quick DOI-resolver check before Zotero entry.** The DOI supplied (`10.1016/j.bspc.2022.103489`) and its PII pattern (`S1746809422000118`) both point to a 2022 article, but the exact year was not visible in the provided text — confirm via doi.org before final citation. The DOI itself is not in question, only the human-readable year field.

**5. Two references have incomplete bibliographic metadata** — resolve before Zotero import:
- **H8** (Seizure-NGCLNet) — exact venue and publication year could not be confirmed from the extracted text (numbers/architecture are otherwise fully verified).
- **E1** and **E2** are pre-DOI-era papers (2000, 2001) — cite by title/PMID in Zotero rather than DOI.
